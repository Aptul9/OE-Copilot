# schermo-web

Lo schermo del telefono virtuale di OE Copilot in una pagina del browser: video, tocchi, tastiera, tasto di accensione. È una copia potata di ws-scrcpy (vedi `UPSTREAM.md`). Gira come servizio `schermo` di `server/docker-compose.yml`, non è pubblicato e non ha password: ci si arriva solo dal Caddy, dopo l'accesso del gateway (GUIDA.md, 4.8).
